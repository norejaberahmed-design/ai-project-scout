# كشاف مشاريع الذكاء الاصطناعي — AI Project Scout

نسخة أولية تبحث عن مستودعات الذكاء الاصطناعي على GitHub وتحفظ سجلًا وتنتج تقريرًا عربيًا. النجوم ليست دليلًا على الطلب أو الربح.

## التشغيل
Python 3.12+: `python -m unittest discover -s tests -v` ثم `python scout.py`.

## حدود صريحة
- البحث في GitHub فقط وليس كل الإنترنت.
- لا تشغّل هذه الأداة مستودعات خارجية.
- لا تجمع هذه النسخة أدلة مقابلات أو استعدادًا للدفع؛ لذا كل فرصة حالتها NEEDS_VALIDATION وقرارها DO_NOT_BUILD_YET.
- GitHub API وActions يخضعان للحصص والحدود. الكاش ليس نسخة احتياطية مضمونة.
- راجع الترخيص الأصلي والتبعيات قبل الاستخدام التجاري.

## بوابة البناء
لا تبنِ منتجًا قبل تحديد المشتري، وإثبات مشكلة مؤلمة بدليل مستقل، ومراجعة المنافسين والبدائل، وحساب التكاليف والتسعير، وتجربة عرض يدوي مع عملاء حقيقيين. عند غياب الأدلة: اترك الفكرة أو أبقها قيد التحقق.


## الأتمتة
يعمل GitHub Actions يوميًا، ويمكن تشغيله يدويًا من تبويب Actions. تُحفظ التقارير كـ artifacts لمدة 30 يومًا. تحقق من سجل التشغيل قبل اعتبار المسح ناجحًا.
