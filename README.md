# كشاف مشاريع الذكاء الاصطناعي — AI Project Scout

وكيل بحث أولي يعمل من سطر الأوامر. يجمع إشارات تقنية من GitHub وإشارات سوق أولية من بحث الويب، ويحفظ تقارير عربية JSON وMarkdown. ليس روبوتًا يضمن الربح، ولا يعتبر نتائج البحث إثباتًا على وجود مشترين.

## تشغيل الوكيل

يتطلب Python 3.12+ ولا يحتاج إلى مكتبات خارجية:

```bash
python -m unittest discover -s tests -v
python agent.py --idea "متابعة الفواتير المتأخرة" --buyer "المدير المالي في الشركات الصغيرة" --market "السعودية"
```

يبحث الوكيل عن المشكلة، والأسعار والمنافسين والبدائل، ومراجعات أو شكاوى محتملة. ثم يجمع إشارات GitHub التقنية، ويحفظ تقريرًا داخل `reports/` وسجلًا تقنيًا داخل `data/`.

مثال لتغيير الفكرة:
```bash
python agent.py --idea "أتمتة عروض الأسعار للموزعين" --buyer "مدير المبيعات" --market "السعودية"
```

## التشغيل الآلي

GitHub Actions يشغّل الاختبارات والبحث يوميًا. لتشغيل الوكيل على فكرة تختارها من الهاتف: افتح تبويب Actions ← AI Project Scout Agent ← Run workflow، ثم أدخل الفكرة والمشتري والسوق. بعد انتهاء التشغيل افتح Artifacts ونزّل تقرير Markdown أو JSON. التقارير تحفظ 30 يومًا. افتح سجل التشغيل للتأكد من النتيجة؛ وجود ملف workflow وحده لا يثبت نجاح التشغيل.

## قواعد القرار

- القرار الافتراضي هو `DO_NOT_BUILD_YET`.
- الشعبية التقنية أو مقتطفات محرك البحث ليست دليلًا على الطلب المدفوع.
- `LEADS_ONLY_NOT_VERIFIED` تعني إشارات تحتاج تحققًا يدويًا.
- لا يثبت الوكيل استعداد العميل للدفع؛ يلزم التواصل مع مشترين حقيقيين واختبار عرض مدفوع.
- لا يتصل الوكيل بالعملاء أو يرسل رسائل نيابة عنك.
- لا ينفذ كود المستودعات التي يعثر عليها.

## حدود ومخاطر

- يعتمد البحث الخارجي على توفر Bing RSS وGitHub API وقد تتغير الخدمات أو تفرض حدودًا.
- البحث محدود وليس مسحًا شاملًا للإنترنت.
- الأسعار والمقتطفات قد تكون قديمة أو غير دقيقة؛ افتح المصادر الأصلية وتحقق منها.
- لا تستخدم درجات GitHub كتقدير للربح.
- راجع التكاليف والتراخيص والخصوصية قبل أي تنفيذ تجاري.
