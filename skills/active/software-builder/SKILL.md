# Software builder

1. Inspect the existing project and preserve working behavior unless replacement is explicitly required.
2. Convert the request into observable acceptance criteria before implementation.
3. Choose the smallest architecture that satisfies the real requirements; avoid unnecessary services and recurring costs.
4. Implement complete vertical slices with real data paths; do not leave mock buttons or placeholder success states.
5. Add tests for validation, errors, core behavior, and security boundaries.
6. Run the available checks and report their actual results.
7. Keep credentials in environment variables and never execute untrusted downloaded code.
8. Document the exact run and deployment steps, including external secrets or manual actions still required.
